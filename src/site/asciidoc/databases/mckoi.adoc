= Mckoi

== Overview

`org.dbunit.ext.mckoi` provides type recognition for the
https://en.wikipedia.org/wiki/Mckoi_SQL_Database[Mckoi] database, a niche/
legacy database. This page is intentionally short.

== IDataTypeFactory

link:/dbunit/apidocs/org/dbunit/ext/mckoi/MckoiDataTypeFactory.html[MckoiDataTypeFactory]
maps Mckoi's SQL type names (`BOOLEAN`, `CHAR`/`CHARACTER`, `VARCHAR`/
`CHARACTER VARYING`/`LONG CHARACTER VARYING`/`TEXT`/`STRING`, `CLOB`, the
integer/numeric family, `DATE`/`TIME`/`TIMESTAMP`, the binary family, and
`JAVA_OBJECT`) onto the matching `DataType` constants. Register it via
`DatabaseConfig.PROPERTY_DATATYPE_FACTORY` — see
link:../properties.html#typefactory[Properties] and
link:../connections.html[Connections & Configuration].

== IMetadataHandler

Not overridden — the default handler applies.

== Connection Preconfiguration Class

link:/dbunit/apidocs/org/dbunit/ext/mckoi/MckoiConnection.html[MckoiConnection]
wraps a JDBC `Connection` and pre-registers `MckoiDataTypeFactory`:

[source,java]
----
IDatabaseConnection connection = new MckoiConnection(jdbcConnection, schema);
----
